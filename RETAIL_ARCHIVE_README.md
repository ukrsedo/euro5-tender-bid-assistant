# Євро5 — роздрібні орієнтири й архів

- Поточна дата: звичайні А-95 та ДП зі стели https://euro5.ua/tsiny-na-palne/. Преміальні марки не підміняють звичайні.
- Попередні дати: точна дата з власного архіву, якщо вона є; інакше історичний Minfin. Майбутня або сьогоднішня ціна не підставляється в стару дату.
- Якщо поточна стела недоступна, використовується лише збережений запис Євро5 на сьогодні. Якщо його немає, орієнтир недоступний; Minfin не підставляється мовчки.
- `data/euro5-retail-history.json` містить щоденні спостереження. Це дата отримання стели, а не підтверджена дата встановлення ціни на кожній АЗС. Архів не відновлює дати до початку збору.
- GitHub Actions `.github/workflows/euro5-price-archive.yml` запускає збір щодня о 08:17 UTC. Розклад GitHub може запускатися із затримкою. При помилці джерела новий запис не створюється. Наявні записи не перезаписуються. У публічному репозиторії після 60 днів без активності GitHub може вимкнути заплановані workflow; їх потрібно повторно ввімкнути.
- 30-денне порівняння вибирає орієнтир на кожну дату за тим самим правилом. Джерела відображаються в поясненні. Євро5 / Minfin — змішане зіставлення орієнтирів, а не чистий часовий ряд однієї мережі.
- Оптовий Enkorr та його контроль через Minfin збережені.

## Cloudflare

У Worker `euro5-tender-bid-assistant` замініть код повним `worker.js` із цього пакета й натисніть Deploy. Існуючі `AI_API_KEY`, `AI_MODEL`, `AI_API_URL` збережіть. Нові секрети та KV не потрібні. Named entrypoint `Euro5CategoryAI` збережений, тому підключення ШІ нового інструмента категорій продовжує використовувати його.

Перед заміною збережіть поточний код Worker. Цей файл підготовлений на основі раніше наданого користувачем повного коду; якщо ви самостійно змінювали Worker після нього, ці додаткові зміни потребують перенесення.

`node scripts/test-retail.mjs` з кореня репозиторію. Довільні ціни не додавайте в архів.
