# Обновление статистической базы на 22 октября 2026

Источник: публичный Prozorro BI, приложение всех лет `2595af2b-985f-4771-aa36-2133e1f89df0`, таблица VcLPJX. Время обновления, указанное самим BI: **22.10.2026 22:00:31**. Это срез BI, а не гарантия загрузки каждого события до 23:59. SHA-256 выгрузки сохранён в `models/validation-2026-10-22.json`.

Получено **24 254 уникальных лота**, объявленных с 01.01.2022 по 22.10.2026, CPV 0913*, ожидаемая стоимость от 1 млн грн в исходной базе. После отбора осталось **10 259 завершённых лотов**. Последнее объявление среди завершённых — 16.10.2026: более поздние незавершённые закупки не превращаются в обучающие результаты. В этой выборке 166 лотов завершились после 05.10; 54 объявлены после 05.10 и успели завершиться к срезу.

## Почему это не прежние 11 858 плюс новые строки

Прежний код обучения отсутствует в репозитории и среди найденных исходников. Сохранены его коэффициенты, справочник заказчиков, ценовые таблицы и проверочная книга. Поэтому создан воспроизводимый новый расчёт с явным отбором. Прежняя модель полностью сохранена как версия 05.10.2026. Утверждать, что новый отбор идентичен старому, нельзя.

В новую выборку входят только моделируемые конкурентные процедуры: запрос цены, открытые и упрощённые закупки, с успешным завершением и хотя бы одним участником. Закупки без использования системы, переговорные и другие немоделируемые процедуры исключены из обучения числа участников. Их история продолжает учитываться отдельно в карточке заказчика.

Исключены неподдерживаемые CPV, неоднозначные названия топлива, явно указанные масла/сжиженный газ/авиационное топливо, стоимость ниже 1 млн без НДС, незавершённые лоты и некорректные цены. Тип топлива определяется по названию и CPV; позиции лота автоматически не перечитываются. Часть названий «Нафта і дистиляти» без уточнения намеренно исключена. Подробные взаимоисключающие причины отбора и числа — в JSON отчёте.

Порог без НДС использует действующую в приложении конвенцию деления на 1,2 при отметке «з ПДВ». Исторические изменения ставок отдельно не восстановлены. Соотношение выигравшей цены и бюджета использует суммы BI; индивидуальный НДС каждого победителя отдельно не проверяется. Это ограничения сопоставимости старых наблюдений.

## Прогноз числа участников

Цель: **один участник против двух и более**, условно на успешное завершение моделируемой закупки. Это не вероятность победы нашей компании и не вероятность отсутствия участников.

Сохранены 13 признаков прежней архитектуры: логарифм бюджета без НДС; число прошлых лотов заказчика; среднее число участников; доля одного участника; число участников последнего доступного результата с ограничением 6; бензин/дизель; четыре типа процедур; признаки талонов и налива в названии.

Для каждой обучающей строки история заказчика строится заново. Результат другого лота становится доступным только после даты его последнего изменения статуса на «завершён». Результаты того же дня исключены; собственный результат и будущие лоты недоступны. История охватывает подходящие лоты с 2022 года. Для нового заказчика: 0 лотов, среднее 2, доля одного участника 0,36, последний результат 2.

Алгоритм: StandardScaler + LogisticRegression(C=1), затем отдельная логистическая калибровка вероятностей. Разбиение календарное, без случайного перемешивания:

| Этап контрольного расчёта | Период | Число лотов |
|---|---|---:|
| Обучение коэффициентов | Объявления с 01.01.2025, завершение до 01.07.2026 | 4 406 |
| Калибровка | Объявления июль–август, завершение до 01.09 | 529 |
| Независимая проверка | Объявления сентябрь–октябрь, завершение к срезу | 466 |

Результаты проверки: точность **73,82%**; ROC AUC **0,7124**; Brier **0,1870**; log loss **0,5670**. Простой прогноз «всегда 2+» даёт 68,45% точности. Та же архитектура без истории заказчика: AUC 0,6386, Brier 0,1980. Это оценка контрольной версии до финального переобучения.

На 54 свежих объявлениях после 05.10 старая версия даёт 83,3% точности, контрольная новая — 85,2%; Brier практически одинаков: 0,11942 и 0,11928. Маленькая выборка не позволяет заявлять доказанное улучшение качества.

Для рабочей версии коэффициенты заново обучены на 5 059 результатах до 01.09, калибровка выполнена на 466 результатах сентября–октября. Следовательно, эти 466 результатов уже не являются независимым тестом именно финальных коэффициентов. Отчёт отдельно сохраняет проверку более ранней версии. Финальный справочник заказчиков обновлён всеми подходящими завершениями до среза.

## Ценовые варианты

Пересчитаны квартильные уровни скидки: 25%, 50%, 75%, 90% распределения, с округлением вверх до 0,25 процентного пункта. Для рынка используются объявления последних 90 календарных дней и результаты, известные к срезу. Для одного участника — 730 дней и только лоты с одним участником. Для каждого вида топлива отдельная выборка, минимум 30 наблюдений.

| Режим | Бензин | Дизель | Смешанное |
|---|---:|---:|---:|
| Рынок: наблюдений | 131 | 520 | 361 |
| Один участник: наблюдений | 319 | 651 | 1 043 |

«Историческая конкурентность» в интерфейсе — контрольная частота, с которой такая позиция цены была бы не выше цены победителя. Она проверена последовательно на сентябрьских–октябрьских объявлениях: для каждого объявления окно цен заканчивается накануне. Частоты объединены по видам топлива внутри режима, как в прежней версии: рынок 32,2 / 66,5 / 84,8 / 94,0%; один участник 36,7 / 63,3 / 81,0 / 93,2%. Число контрольных примеров соответственно 466 и 147. Это исторические частоты, не вероятность победы. Доли внутри финального обучающего окна сохранены отдельно как `in_window_coverage`.

## Версии по дате объявления

Новая модель допустима для объявлений **от 23.10.2026**. Для объявлений 06–22.10 Worker выбирает сохранённую версию 05.10; frontend и PDF используют соответствующие ценовые таблицы. Поэтому тестовый тендер UA-2026-10-13-014119-a сохраняет прежний прогноз и цены. Результат его нынешних торгов не подставляется в прогноз на 13 октября. Для объявлений до 06.10 либо без установленной даты статистический прогноз не выдаётся: нет подходящей исторической версии.

Нельзя использовать коэффициенты, обученные до 22 октября, как честный прогноз на 13 октября. При необходимости нового ретроспективного прогноза потребуется отдельное обучение с более ранним срезом.

Пятидневный риск изменения себестоимости — отдельная модель рыночных цен; он продолжает отсчитываться от введённой даты подачи предложения. Штрафы за концентрацию побед в карточке заказчика сохранены как управленческое правило и не переобучаются как статистическая вероятность.

## Воспроизведение и применение

Зависимости зафиксированы в `scripts/requirements-model.txt`. Исходная выгрузка и очищенная выборка приложены в архиве обновления.

```sh
python3 scripts/retrain-model.py bi-fuel-all-2026-10-22.jsonl.gz models
python3 scripts/build-model-assets.py
node scripts/test-model-version.mjs
node scripts/test-buyer-competition.mjs
node scripts/test-buyer-history.mjs
node scripts/test-price-risk.mjs
node scripts/test-submission-risk.mjs
```

`export-training-bi.py OUTPUT.jsonl.gz` повторяет отбор из публичного BI. Новый запуск позднее может получить уже другой срез; он не восстановит старый срез без сохранённой выгрузки. При следующем обновлении нужно изменить дату и версию, проверить дату обновления BI и сохранить новый исходный файл.

Frontend обновляется через GitHub. Для рабочего API требуется заменить полный `worker.js` в Cloudflare и выполнить Deploy, сохранив имеющиеся переменные и секреты. Версия `/health`: `2026.10.23-model-20261022`. Публикация Worker автоматически не выполнена.
